# MULTI-CHEF — Руководство пользователя

> «Меню недели из того, что есть в холодильнике.»
> Web: https://multi-chef.431a.ru · PWA на iOS/Android · Без рекламы · Без подписок

## 1. Регистрация

1. Откройте https://multi-chef.431a.ru/ в браузере.
2. Нажмите **«Начать»** → **«Создать аккаунт»**.
3. Введите email и пароль (≥ 8 символов, ≥ 1 цифра, ≥ 1 заглавная).
4. Введите название вашего домохозяйства (например «Семья Петровых»).
5. Готово — вы автоматически перейдёте на `/today`.

> 💡 Каждое домохозяйство изолировано от других. Все продукты, рецепты и списки покупок — только ваши.

## 2. Добавить продукты в холодильник

1. Перейдите на `/fridge` (или нажмите иконку «Холодильник» внизу).
2. Нажмите **«+ Добавить продукт»**.
3. Введите название (например «молоко», «яйца», «курица»).
4. Укажите количество (граммы) и место хранения:
   - **FRIDGE** — холодильник
   - **FREEZER** — морозилка
   - **PANTRY** — шкаф / кладовка
   - **COUNTER** — стол / открытое хранение
5. Если знаете срок годности — поставьте дату `expiresAt` (опционально).
6. Нажмите **«Сохранить»**.

> 💡 Продукт появится в вашем холодильнике мгновенно и станет доступен для планирования меню.

## 3. Спланировать меню на неделю

1. Перейдите на `/today` (или `/plan` для недельного вида).
2. Нажмите **«Сгенерировать меню»**.
3. Wizard спросит:
   - Сколько персон
   - Какие приёмы пищи (завтрак / обед / ужин / перекусы)
   - Аллергии / исключения (без глютена, без молока, без свинины)
   - Сложность рецептов (простые / средние / сложные)
   - Бюджет (эконом / стандарт / без ограничений)
4. Нажмите **«Сгенерировать»** — подождите 10-30 сек.
5. Получите план на 7 дней. Для каждого дня:
   - Нажмите на блюдо → ингредиенты
   - Нажмите **«Принять»** чтобы добавить в план
   - Нажмите **«Заменить»** чтобы получить альтернативу
6. Принятые блюда автоматически добавят нужные продукты в список покупок.

> 💡 Можно перепланировать отдельный день или всё меню. История планов хранится 90 дней.

## 4. Список покупок

1. Перейдите на `/shopping`.
2. Список автоматически сформирован из принятого плана.
3. Чекбоксы — отмечайте купленное.
4. Нажмите **«Очистить купленные»** — они перенесутся в ваш холодильник с реальными датами покупки.

> 💡 Список сортируется по отделам магазина (молочный → мясо → овощи → бакалея).

## 5. Установить PWA на телефон

### iOS (iPhone / iPad, Safari)

1. Откройте https://multi-chef.431a.ru/ в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран Домой»**.
4. Нажмите **«Добавить»**.
5. Иконка «Мультишеф» появится на главном экране.
6. Откройте её — приложение запустится в полноэкранном режиме (без адресной строки Safari).

### Android (Chrome)

1. Откройте https://multi-chef.431a.ru/ в **Chrome**.
2. Нажмите меню (три точки) → **«Добавить на главный экран»** или **«Установить приложение»**.
3. Подтвердите.
4. Иконка «Мультишеф» появится на главном экране.

> 💡 После установки PWA работает оффлайн (последний загруженный план кэшируется).

## 6. Безопасность

- **Пароль** — хранится как Argon2id-хэш. Восстановление через email.
- **Сессия** — 30 дней с автопродлением. Выйти можно через `/profile` → «Выйти».
- **CSRF** — защита от подделки запросов автоматическая.
- **RLS** — данные других домохозяйств физически изолированы на уровне БД.

## 7. Поддержка

- Email: ваш зарегистрированный email для обратной связи.
- Telegram: alert-канал для инцидентов на стороне сервера.
