# perenos — handover-набор для нового разработчика

**Дата:** 2026-09-12
**Назначение:** передача доступа и контекста проекта MULTI-CHEF фулстек-разработчику на другом сервере.

---

## ⚠️ ВАЖНО: секретный материал НЕ выложен целиком

По соображениям безопасности **PAT, private SSH keys, .env-файлы с API-ключами НЕ лежат в этой папке в виде plain text**. Их нужно либо:
- скопировать вручную (вытащить из источника — указано ниже), либо
- переслать по защищённому каналу (1Password / Bitwarden / SecureCRT / иной vault).

## Что лежит в этой папке

| Файл | Назначение |
|---|---|
| `README.md` | этот файл — индекс |
| `HANDOVER-TO-NEW-DEVELOPER.md` | полный проект-handover (19 KB) |
| `SHORT-PROMPT-FOR-NEW-DEVELOPER.md` | короткий промт copy-paste в чат с разрабом (5.8 KB) |
| `access-map.md` | **карта доступа**: что где лежит, как достать, как использовать |
| `SERVER-INFO.md` | настройки сервера, nginx, порты, утилиты |

## Чек-лист передачи

- [ ] Создать нового пользователя на сервере (опционально, см. `SERVER-INFO.md`)
- [ ] Добавить SSH-ключ разраба в `~/.ssh/authorized_keys` (отдельный от root)
- [ ] Передать **GitHub PAT** новому разрабу (через vault — НЕ через чат)
- [ ] Передать пароль от БД, если есть (есть в `.env` каждого сервиса)
- [ ] Передать URL прода (если есть)
- [ ] Передать .env-файлы для локального запуска (`apps/api/.env`, `apps/web/.env`, пакеты)
- [ ] Передать SSH-ключ Actions (если разраб будет пушить в CI)

## Что НЕ передавать

- ❌ Приватные SSH-ключи других разработчиков
- ❌ Ключи CI/CD (`/root/.ssh/id_ed25519_actions_deploy`) — это ключ сервера для runner'ов
- ❌ Production-API-ключи (если есть) без смены
