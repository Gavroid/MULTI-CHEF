## 2026-09-10 — MC-034 user gate (принял как тактические)

### 21:21 — MC-034 web /today
**Контекст:** архитектор вернул ADR с 5 открытыми вопросами по UX-тактике.

**Решения:**
1. **Дисклеймер КБЖУ**: ссылка «Подробнее о КБЖУ» → `/recipe/[id]`, **НЕ дублируем** плашку на карточке /today. Причина: консистентность с MC-035, где дисклеймер уже на детальной странице.
2. **`GET /profile` graceful fallback**: при недоступности — пустой `preferences={}`, не краш. UI: hero CTA показывает «Добавьте продукты в холодильник» без аллергенов.
3. **«Срочно» quick-scenario = MINIMAL + maxMinutes=20 + [SHORT_TIME, NO_MULTISTEP]**. Причина: PRD §2.3.2 перечисляет «Срочно» как «быстро и дёшево».
4. **loading 500 мс**: оптический сkeleton-стадии «продукты» → «аллергены» → «recommendations», но показывать только если POST > 200 мс. Иначе мгновенный redirect на /today/result.
5. **`/shopping/[listId]` заглушка**: создаём сразу (deep-link после «Готовлю это»), иначе wizard падает в 404.

**Альтернативы (не выбрал):**
- Кнопка «Готовлю это» сохраняла бы план БЕЗ редиректа → modal-окно с shopping list inline. Не выбрал: загромождает UX, MC-056 сделает нативно.

**Уверенность:** HIGH для 1, 4, 5. MEDIUM для 2, 3 (можно потом подкрутить).
