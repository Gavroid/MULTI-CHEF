## HIGH (D)

### D-H1. **`<Link passHref legacyBehavior>` в `BottomTabBar.tsx:104`** — `legacyBehavior` **deprecated** в Next.js 15.0+ (replaced by automatic <a> wrapping)
- **Файл:** `apps/web/src/components/BottomTabBar.tsx:103-106`.
- **Что:** текущий код:
  ```tsx
  <Link href={tab.href} passHref legacyBehavior>
    <TabItem tab={tab} isActive={tab.id === activeId} />
  </Link>
  ```
  В Next 15.1 `passHref` + `legacyBehavior` помечены как deprecated. После Next 16 — могут убрать. TabItem рендерит `<a>` сам (line 56 `href={href}`), конфликт не очевиден, но варнинги в build.
- **Воспроизведение:** `pnpm build` в R14 собирает зелёный, но это потому что пока ещё работает. Через 1-2 версии Next — сломается.
- **Severity:** HIGH (техугл, но избежит breakage).
- **Фикс:** переписать TabItem, чтобы он не рендерил `<a>` (использовать `useRouter` для nav), либо оставить legacyBehavior до миграции + починить в спринте.

### D-H2. **`aria-current='page'` устанавливается только когда active**, но фокус-визуализация есть (focus-visible ring) → **проблема: при переходе на новую страницу фокус остаётся на tab-bar, screen-reader не объявляет смену роута.**
- **Файл:** `apps/web/src/components/BottomTabBar.tsx:56`.
- **Что:** `<nav aria-label>` — корректно, но после `router.push` фокус остаётся на ссылке. Screen-reader пользователь должен вручную нажать next/pgdn.
- **Фикс:** `useFocusOnLocationChange` хук, переносящий фокус на `<main>` после смены пути.

## MED (D)

### D-M1. **`UseToast` (UI primitives)**: Toast заменяет активный, если новый приходит в течение 4s — **пользователь может пропустить важные errors**, например logout-failure.
- **Файл:** `packages/ui/src/components/Toast.tsx:101`.
- **Что:** single-slot queue заменяет активный. PRD §2.5.5 «single-slot», но **critical errors (logout-failure) могут быть переписаны обычным success info**.
- **Фикс:** priority-queue: `danger`/`warning` имеют приоритет над `info`/`success`.

### D-M2. **`/today/loading/page.tsx` `LoadingClient.tsx` не имеет fallback если `?budget=&time=&anti=` отсутствуют**
- **Файл:** `apps/web/src/app/(app)/today/loading/LoadingClient.tsx:103` (line `parseSettings`).
- **Что:** если POST вызывают без query string → `parseSettings(null, null, null)` → defaults → но если POST возвращает 422, то redirect с `?ref=` НЕ состоится. UI должен показать error.
- **Фикс:** проверить и покрыть cases.

### D-M3. **`Chip` (Toggle) нет `aria-pressed`**
- **Файл:** `packages/ui/src/components/Chip.tsx`.
- **Что:** toggleable Chip в BottomTabBar фильтрах (`/fridge` archive/active) рендерит без `aria-pressed`. screen-reader пользователь не знает состояние.
- **Фикс:** добавить `aria-pressed={selected}`.

### D-M4. **Card components не имеют role="region" или aria-labelledby** для длинного содержания.
- **Файл:** `packages/ui/src/components/Card.tsx`.

## LOW (D)

### D-L1. **Наследуемая анимация**: spinner в Button использует `animate-spin` Tailwind. Не учитывает `prefers-reduced-motion`.
- **Фикс:** wrap в `@media (prefers-reduced-motion: reduce) { animation-duration: 0 }`.

### D-L2. **theme toggle** не имеет announce-region: после клика screen-reader не слышит "тема изменена".
- **Файл:** `apps/web/src/components/ThemeToggle.tsx`.

### D-L3. **BottomSheet** (открывается через AddPantryItemDialog) — нет focus-trap.
- **Файл:** `apps/web/src/components/BottomSheet.tsx`.

### D-L4. **No `lang="ru"` для пользовательского ru-локали**, но `html lang="ru"` есть в layout.tsx:26 — OK.

## Сводный вывод D

- UI в порядке для quick-фикса: **D-H1** (legacyBehavior) предсказуемо сломается при Next 16; **D-H2** (focus management) — мелкая доработка.
- Design-system (`packages/ui`) сделан хорошо — `forwardRef`, `useId` для label/input, ARIA-valid.
- **Главное узкое место**: **BottomSheet без focus-trap** и **no reduced-motion support** — это a11y debt.
- Bundle sizes в норме. Mobile-first соблюден (viewport 414×896 в playwright).

D не blocker — D + план-фиксы из B1-B4 вместе = большая стратегия polish, но не влияет на корректность основного флоу (4 блокера из C выше).
